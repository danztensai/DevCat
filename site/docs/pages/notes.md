# Notes

Keep Markdown notes next to your work, per project or for everything, saved as you type.

![A note in Edit and Preview](../img/notes.png)

## Write a note

1. Click **Notes** in the left bar.
2. Click **New note**.
3. Write in Markdown. The note saves as you type; <kbd>⌘S</kbd> (<kbd>Ctrl+S</kbd>) saves at once.

Switch between **Edit** and **Preview** with the buttons or <kbd>⇧⌘V</kbd> (<kbd>Ctrl+Shift+V</kbd>).

## Organize notes

- A note belongs to a **project** (shown only while that project is focused) or to **General** (shown everywhere).
- Move a note to another project at any time.
- **Pin** the notes you need most so they stay on top.
- Search finds notes by title and text.
